# Security Policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or pull request.

Use **Report a vulnerability** on the Security tab of this repository. If that button is missing, open an issue that says only that you need a private security contact, and include no details.

Include what you found, the steps to reproduce it, and the version or commit you tested.

## Supported versions

Only the default branch and the latest release receive security fixes.
